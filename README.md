# ebook-dio
ebook bootcamp ia dio
ítulo:

crie 5 variações de título de um e-book k sobre o tema 164 anos da caixa econômica federal, o e-book tema é do nicho de importância para a população brasileira e o subnicho é aniversario da caixa, o título deve ser simples e curto , e tenha uma temática mais social

 

Desenvolvimento texto:

Faça um texto  para ebook, com foco nos 164 anos da caixa economica federal, listando os principais tópicos  ou marcos da sua trajetória junto a população brasileira.

( REGRAS)

> exemplificar sempre de uma maneira simples

>deixe o texto enxuto

>sempre traga exemplos em contexto real

>crie um nome

 

Para cada capítulo :

Faça um texto  para ebook, com foco ( título do capitulo) , listando os principais marcos das ações da Caixa junto ao povo brasileiro.

 

Para a Conclusão:

Escreva uma conclusão referente aos textos acima salientando a importância da CAIXA junto aos brasileiros e como fomentador de politicas publicas e socias.texto curto, objetico e impactante para o leitor em um tom de voz semelhante a palestra do Cortela.
